# Listening Guide

This is the compact proof surface for the instrument.

## Known-Good First Listen
1. Flash the current firmware.
2. Start MIDI clock at 90 BPM.
3. Toggle a few gates on rows A and B.
4. Listen on headphones or line out.

You should hear:
- the step highlight advance in lockstep with MIDI clock
- bundled demo slices fire on lit steps
- rows phase against each other when their source material differs

## What To Listen For

### 1. Clock discipline
- Start should begin playback cleanly.
- Stop should freeze motion.
- Continue should resume without the grid losing itself.

### 2. Phase drift
- Same gate pattern on different rows should not sound static for long.
- The evolving rhythm comes from source content, not from changing the sequence.

### 3. Velocity and probability
- Shift + lit step should change the accent feel.
- Alt + lit step should create repeatable variation by reducing how often a step fires.

### 4. Stutter and FX
- Shift + lit step should add a short performative burst without rewriting the pattern.
- Shift + Alt on steps 1-4 should change tone immediately while playback remains stable.

### 5. Recovery workflow
- Record a new take on a row.
- Restore the previous take on that row.
- Reslice the row and confirm the gates remain intact.

## Recommended Demo Order
- Clocked grid
- Phase drift
- Velocity lanes
- Probability lanes
- Stutter
- Record and reslice
